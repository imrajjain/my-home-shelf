# Shelf's Homebrew tap

The contents of this folder go in the public `imrajjain/homebrew-tap`
repository (Homebrew finds taps by that `homebrew-` name).

```bash
brew install --cask imrajjain/tap/shelf
```

`apps/macos/scripts/release.sh … --publish` keeps `Casks/shelf.rb` there in
step with each release.
